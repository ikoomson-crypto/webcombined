📖 How Social Security Works (Ghana SSNIT System)

  • Monthly Threshold: Social Security is calculated on Basic Salary only up to the monthly threshold.
  • Calculation: SS = MIN(Monthly Salary, Monthly Threshold) × Rate
  • Example: If salary is GHS 20,000 and threshold is GHS 15,000, SS is calculated on GHS 15,000.
  • Monthly Override: You can set a different threshold for any specific month.
  • Deduction Order: Social Security is deducted BEFORE tax is calculated.
  • Reset: The threshold resets every month (not annually).
